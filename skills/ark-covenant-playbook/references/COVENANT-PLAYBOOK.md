# 七条盟约路线：专家候选核心与引擎机制对照（2026-10-25）

本名单来自所有者本轮提供的经验，作为开放候选核心的软先验，不是穷尽名单，也不是已验证的最优策略。下文数值与触发条件来自固定模拟器；构筑顺序、保留和转型建议是据此提出的待评估策略。没有新对局、训练、奖励修改或模型晋升。

引擎：`c9d804f470b8d7422ae04eb66faf671cef21ad52`，app 0.3.1；核对外部只读检出 `ArkGuardRL-migrate-031/runtime/engine031`。本报告不复制引擎数据文件、资产或轨迹。实验所用 Core 身份仍由 `CORE_DEPENDENCY.json` 固定，本轮没有变更执行身份。

## 共同规则与名单规范

- 名称归一：“维纳”对应维娜·维多利亚，“暇光”对应瑕光。百炼嘉维尔常规可见版本为四阶 `chess_char_4_23_a`；五阶 `chess_char_5_18_a` 隐藏且不可见，不作为常规商店目标。
- 七条核心盟约首阈值都是场上三名不同干员；上档通常六名，炎还有九名，阿戈尔上档是五名。拥有、放在整备区与实际上场激活不能混为一谈。不同副盟约有自己的计数范围与门槛。
- 多数成长特质要求盟约已激活；先拿到成长卡、却不部署凑齐首阈值，可能整回合没有收益。忍冬的获得时加层明确无需激活，是例外。
- “不同阶”是棋子阶数多样性；同阶多名不增加该项。金棋不等于升一阶，不能用金棋数量替代阶数覆盖。
- 金棋价值分三部分：即时战力、特质升级、合成触发的检索。已核对检索在合成时按 `min(当前本+1,6)` 创建，通常免费三选一；有不足候选时的向下补位。三选一内容生成后再升本不能抬高其阶数，低本凑对子与低本立即完成合成应分开决策，详见 [金棋检索设计](MERGE-SEARCH-STRATEGY.md)。
- “进入休整期”“休整期结束”“部署”“开启技能”“击倒”是不同事件。阵容看似成形，事件不发生、站位不满足，仍不能兑现成长。

## 维多利亚：阶数覆盖 → 层数 → 重锤 → 装备输出

**确认机制。** 基础盟约增伤只给携带装备的维多利亚成员；每累计25层发一件随机效果维式重锤。六维多利亚增加携装成员攻击力，升级装备还有额外收益。

- 薄绿（三阶）：结束休整时，每个在场维多利亚阶数贡献2层，金棋4层。她是低成本成长入口，不只是输出候选。
- 号角（五阶）：为当前已激活且层数最高的盟约，按其在场不同阶数每阶加2层，金棋4层。效果不锁定维多利亚；其他盟约层数更高时会喂给其他路线。
- 维娜·维多利亚（六阶）：按在场维多利亚不同阶数每阶+3层；按奇迹不同阶数每阶+2层，均要求对应盟约激活；金棋分别6/4。数据中两条特质分管两盟约，不把重复的合并描述累计两遍。

**构筑建议。** 薄绿配低阶不同名成员先激活，健康时补不同阶、号角和装备；维娜是高阶升级目标，不应成为开始经营的前提。结束休整前检查成长卡在场与装备实际分配。不能为了保留多个阶数而无条件留下弱卡，也不能把所有装备堆给一个成员后默认全队都享受携装增伤。号角的支持对象须从真实层数读取，避免“买了号角就认定主修成长”。

## 炎：获得干员驱动成长，灵巧/奥术把成长兑现为输出

**确认机制。** 三炎按层数增加成员攻击力；六炎开场召唤炎佑，收集炎成员攻击力与生命总和的30%作为属性贡献；九炎变为两只并强化。模拟器还保留炎佑模板基础属性，不能简单等同于总和乘30%。

- 小满（二阶，炎/灵巧）：结束休整时，本回合每获得一名干员，已激活炎+1层，金棋+2。
- 夕（五阶，炎/奥术）：相同获得计数，为已激活炎、奥术分别+2层，金棋+4。需要各自激活；有夕不等于自动激活奥术。
- 灵巧两名激活，给灵巧成员和周围四格攻速，40层扩至八格；奥术两名激活，成员法伤给目标挂短时法伤易伤，三名进一步强化半血以下目标的效果。

**构筑建议。** 小满可以先建立低阶成长路线；夕同时补法伤和奥术成长。可比较“买能上场/合成/卖出回收的有效棋子”与刷新，不能只因有按获得数成长就盲买废牌。获得计数来自实际 `acquireChess`，包括购买、奖励、效果发放，不仅是购买次数；普通合成不会凭空再算一次额外获得。结束休整才检查成长卡及盟约，因此本回合后拿到并上场的小满/夕也可利用本回合既有获得计数。六炎是可评估的成形目标，需要同时看炎成员真实属性与部署格，不能仅用“人数更多”推断强度。按所有者建议优先考虑灵巧、奥术；尚未验证它们在所有局面都优于其他配套。

## 卡西米尔：部署事件叠攻击，瑕光与砾承担不同循环

**确认机制。** 任意我方干员部署，卡西米尔成员攻击力+20%，持续至战斗结束，上限随层数变动。六人时，阻挡者周期范围真伤，未阻挡者攻击附带真伤。

- 瑕光（三阶，卡西米尔/突袭）：每次部署给自身已激活盟约+4层，每战最多12层；金棋+8、最多24。突袭达两名才激活，并且只有符合无目标等触发条件的突袭成员才会自动再部署，保留技力。
- 砾（二阶，卡西米尔/不屈）：部署时卡西米尔+1；被击倒时已激活不屈+2，金棋分别2/4。数据75与143不是部署加层各算一次：75负责倒地，143负责部署。
- 不屈两名激活，为地面干员倒地提供概率立即再部署；三名额外在地面干员倒地时给全体技力。砾本身不是突袭成员，不能因为队伍激活突袭就说砾也会突袭移动。

**构筑建议。** 三卡西米尔先启动，瑕光补第二突袭形成部署成长；砾配不屈形成倒地/再部署方向，二者合起来供给部署事件。关注实际再部署次数、瑕光是否达到单战成长上限，以及成员是否真能接敌。不要为刷事件主动破坏防线。六人档阻挡与非阻挡收益不同，站位和敌人路线需要一起评价。

## 拉特兰：高阶弹药引擎，莫斯提马是邻接成长辅助

**确认机制。** 三拉特兰按层数提高成员开技能时获得的弹药；六人时成员每消耗一发，给全体拉特兰叠攻击，有上限。只有真实弹药技能与消耗事件能驱动这条链，普通攻击次数不能替代弹药数。

- 圣约送葬人（五阶，拉特兰/远见）：自身每消耗7发，已激活拉特兰+7层、远见+3层；金棋14/6，分别有每场49/21、98/42层上限。数据23/55拆分两个盟约，不重复计算描述。技能有12发基础弹药，受击有概率闪避补弹，需要接敌与生存。
- 莫斯提马（四阶，拉特兰/奥术）：周围四格成员每消耗6发，已激活拉特兰+1层，金棋+2。她自身选用技能不是弹药技能，职责是围绕弹药手布置的成长辅助与控制，不是“所有攻击都算弹药”。

**构筑建议。** 接受所有者“核心在高本”的经验：可以低阶拉特兰过渡，但不要为三人标签过早锁死。检索出现圣约送葬人时再比较弹药成员、前线生存、莫斯提马邻接格和转型成本。远见也需另外激活后才接到该部分成长。攻速、回技与更多弹药的价值要用单位实际技能规则评价；攻击回复与自然回复不应统一按同一种装备收益排序。

## 阿戈尔：吞噬站位、供体与复活优先

**专家判断。** 所有者认为不太需要专门叠层，优先不屈；这表示策略侧的相对优先级，不代表盟约没有层数收益。未提供单一核心名单，本报告不擅自补成固定白名单。

**确认机制。** 三阿戈尔按层数增加生命；开场标记并吞噬面前一格的干员，可沿阿戈尔链继续，取得供体基础攻击与阻挡数，并对供体结算5000物理性质的损失。攻击是最终加算，不应假设还吃吞噬者所有攻击百分比乘区。被吞噬目标按自身阶数增加层数；层数不是只有手工专门经营才会增长。五阿戈尔提供总计前三次符合条件的成员首次倒地立即复活，不是每人无限复活。

**构筑建议。** 先检查朝向、前格供体、吞噬链及开场损失，避免吞掉唯一关键前线或辅助；再考虑不屈提供地面倒地再部署与三人档回技。供体不一定会死，5000并非无条件处决；复活、不屈、技能触发均须按真实事件记录。归溟幽灵鲨（五阶，阿戈尔/不屈）是引擎可见的桥接成员示例，不能据此宣称它就是所有者指定的必选核心。多人联防还涉及队友棋子和战斗继承，与单人供体布置要分别验证。

## 萨尔贡：回技/控制驱动的技能循环，佩佩补装备经济

**确认机制。** 成员开技能给萨尔贡成员加攻速，每层独立计时，持续时间受盟约层数影响；六人档还加攻击。层数主要改善覆盖，技能事件频率也同样关键。存在策略改写六人效果的分支，不能脱离当前策略身份统一判断。

- 菲莱（三阶）：每开技能给已激活萨尔贡+6层，金棋12；低阶启动点。
- 百炼嘉维尔（常规四阶）：每开技能+9层，金棋18；兼顾前线与成长。选用技能含伤害延后结算，不能把技能期间存活当作战斗风险已经消失。
- 缇缇（五阶，萨尔贡/精准）：范围内敌人或干员进入沉睡/晕眩，每次给已激活萨尔贡、精准+1层，单战最多24；金棋2/48。她自己技能提供睡眠，外部控制也可能帮助成长，但必须发生在她的范围内；不是全场任意控制都计数。
- 佩佩（六阶，萨尔贡/不屈）：技能攻击带晕眩，可为缇缇提供事件；进入休整时发盟约之币/萨尔贡浓茶，有概率黄沙罗盘；金棋增加产物数量。浓茶增加自然回技；罗盘提供初始技力、首次技能结束回技，同时携带浓茶时，萨尔贡持有者每次开技能给全体萨尔贡回3技力。产物须实际使用/装备，入手不自动生效。

**构筑建议。** 菲莱/嘉维尔先建立三人技能成长，观察真实开技能频率；取得缇缇后再重视范围内控制，佩佩兼顾晕眩与回技装备链。优先级不是单按阶数排列：当前缺前线、控制、自然回技或输出，答案会不同。短技能周期不总优于长技能，需同时看技能覆盖、存活与击杀；不能直接奖励频繁开技能而忽略战果。

## 叙拉古：刷新成长、击倒成长与铃兰—忍冬是三条子链

**确认机制。** 三人档部署给成员攻速，持续时间受层数影响；六人档同时间隐匿，并在隐匿及结束后10秒内提供普通伤害命中的概率真伤/恐惧触发。重复部署与真实命中能帮助兑现，不是站着有层数就等价于输出。

- 拉普兰德（二阶）：在场或整备区均可；每个实例本回合见到的首次主动刷新，已激活叙拉古+4层，金棋8。自动/重触发刷新不按主动刷新计。实现按实例计数，新取得副本或本回合合成的新金棋有自己的首次计数；同一实例反复主动刷新不持续获得此收益。
- 缄默德克萨斯（四阶，叙拉古/突袭）：进入休整时给一次免费刷新，金棋两次。要提前在场等待进入休整事件，不能本回合拿到就假定已经领过；其部署技能也让有效再部署有战斗价值。
- 荒芜拉普兰德（六阶）：自身击倒敌人给已激活叙拉古+2层；金棋开场把该击倒特质赋给全体叙拉古成员，是特质覆盖变化而不仅翻倍属性。实现还有成长上限，不能写为无限叠层。
- 忍冬（三阶，叙拉古/迅捷）：获得时两所属盟约各+6层，无需激活；金棋12。铃兰（五阶，叙拉古/协防干员）进入休整时重触发身前一格其他干员的获得时特质，金棋看身前两格。因此将忍冬放在铃兰身前并保持朝向/位置，可重复获得叙拉古与迅捷成长。

**构筑建议。** 拉普兰德低阶启动，先确保三叙拉古并利用首次主动刷新；异德降低刷新资金负担，不能把免费额度用完后的一切付费刷新都解释为必要成长。荒芜拉普兰德是后期输出/击倒成长与金棋优先级候选；铃兰—忍冬则是可较早规划的跨回合成长链。铃兰不能触发异德的“进入休整”或小满的“结束休整”特质，事件类型不匹配。低血时仍应比较一次刷新能带来的真实提升与直接买牌、换阵、结束休整，避免恢复此前无目标的刷新消耗。

## 给后续学习的标注方式

核心身份按条件表示，而不是每条路线只标一个名字：

1. **角色**：启动成长 / 放大成长 / 主要输出 / 控制与前线 / 装备经济 / 跨盟约桥接；同一卡可多角色。
2. **事件与条件**：所需盟约激活、实际站位/方向、不同阶覆盖、装备、技能/弹药、首次事件、单战上限。
3. **当前缺口**：还缺几名可部署成员、是否缺前线、能否在本回合或下回合触发，不能只数拥有名单。
4. **金棋的边际收益**：数值翻倍与改变覆盖范围分开，尤其荒芜拉普兰德；与合成检索价值分开记录。
5. **承诺与转型**：拿到候选核心后比较可执行组合与生存成本，再决定主修；允许跨盟约辅助、部分组件留整备区、以及卖出过渡金棋。

这份先验适合辅助三选一核心选择、任务标签和示范审阅。后续先检验“触发是否兑现”：例如不同阶确实加层、弹药确实消耗、铃兰确实触发忍冬，再比较生存。暂不把每次购买、刷新、倒地或开技能分别发固定正奖励；这些只是手段，容易制造刷事件行为。模型仍需从同预算、保留独立种子与原 BC 参照的实验中学习条件价值，不能把这份玩法说明当作强度证明。

- `server/match/effectsMeta.js`：在场条件与整备区派发；`server/match/pool.js`：可见基础棋子与本局禁用过滤；`server/match/player/acquire.js`：真实获得计数与合成奖励。
