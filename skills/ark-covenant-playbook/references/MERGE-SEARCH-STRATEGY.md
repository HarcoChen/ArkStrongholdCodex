# 金棋作为高阶检索入口：策略修正（2026-10-25）

来源：所有者指出，金棋不仅提供战力，更提供一次目标阶检索；合理路线可以先在低本
积累合成条件，通过检索取得关键核心，再决定玩法和盟约。本文件修正下一步研究设计，
不修改已有报告、规则源码、检查点、奖励或已封存运行。没有新训练/对局或强度结论。

## 已核对的当前模拟器机制

外部引擎固定 `c9d804f470b8d7422ae04eb66faf671cef21ad52`，app 0.3.1。
直接读取其 GPL 源码与绑定公共配置，没有读取隐藏卡池作为策略输入：

- `server/match/player/acquire.js:_mergeChess` 在合成成功、增加 `stats.merges` 后调用
  `pushRewardOffer('merge')`；普通直接 `promote()` 不走这条检索奖励路径。
- `pushRewardOffer` 使用调用当时的 `shop.level`；公共配置为 count=3、tierOffset=1、
  maxTier=6、price=0，得到 `min(本+1,6)` 的免费三选一。三个候选不重复，显示时
  不预留库存；当前实现若指定阶没有足够不同候选，会逐阶向下补位。
- 奖励内容在合成时创建并入队。合成后再升本、然后领取，不能把这份已生成奖励提高
  一阶。应区分“低本收集对子”和“现在完成合成”；先升本再买第三张是一个可比较的
  顺序选择，而不是无条件更优。
- `player/prep.js:pickReward` 从第一个排队 offer 选一项，普通手牌区满仍会拒绝。
  合成可能返还装备、生成临时区物品；检索后的入手、放置和再合成需要一并管理。

源码和数据身份沿用已有实验中的独立引擎/data SHA，不把上述模拟器行为推广为
未经核对的其他版本规则。

## 之前设计漏掉的链条

1. `promotion_transition.purchase` 仅在某个 base 已部署或属于预定主修时，把合成视为
   “有用晋升”；这会低估以检索机会为目的的非主修低费对子。
2. 旧策略给板上金棋很大的保留分数，混淆了“完成合成时获得检索价值”和“这张金棋
   此后值得继续占格”的两个问题。检索价值已经兑现后，过渡金棋仍可为更合理的核心
   阵容让位，不能只因它是金棋而长期保留。
3. 研究经营头的选项只有 buy/refresh/level/ready，真人 intake 没有学习 g.reward。
   执行器仍将 g.reward 交回原 BC 的 mandatory 分支；主修规划器没有选择奖励牌。
4. 当前主修从拥有普通成员开始选择，并可能因已激活而一直锁定。即使检索取得真正
   能定义构筑的高阶核心，控制器也缺少按其机制重新选路线的决策。不能将“一个单位
   有核心羁绊”自动等同于“它是值得围绕构筑的核心卡”。

## 下一步应采用的任务结构（尚未实现）

`保血过渡 / 积累对子 → 选择合成时点与目标奖励阶 → 三选一挑核心 → 确定主修 → 构筑 / 晋升循环`

- **对子积累阶段**：暂定而非锁死主修；用当前过渡阵容生存，考虑可负担的晋升进度、
  手牌容量、合成奖励潜力和剩余生存窗口。非主修对子也可能有检索价值。
- **升本—合成联合决策**：比较现在合成取得 R 阶奖励，与先升本再合成取得 R+1 阶
  奖励；记录花费后还能否买到第三张、是否会挤空棋盘、是否有空间领取。不可用未来
  三选一具体内容作输入，也不能为了奖励阶数让当前局面无条件挨打。
- **检索选择头**：显式处理真实 g.reward 候选，按牌自身机制、立即过渡作用、
  已有组件/装备和可构建路线评价；支持“接受一个新核心并换主修”，而非只选当前
  羁绊成员或只看 tier。只对已经看见的选项评分，不读取隐藏剩余卡池。
- **核心落地阶段**：在取得可构筑核心后，再增强主修承诺；为它购买、保留、换人、
  装备和布阵。淘汰金棋也应按当前作用评价，不回头把已经消耗的合成成本当作保留理由。
- **真人数据**：从完整房间/席位序列中提取“对子积累、合成时本数、真实奖励选项、
  奖励选择、随后阵容/主修变化”的监督材料。结果可作为训练标签，但行动输入仍只含
  当时可见信息；推断的阶段/核心标签需单独审阅，不能冒充真人显式意图。

后续应使用新的 controller/feature/teacher/BC 身份，先实现可记录的规则/选择基线再
做有界同种子对照；新检索头单独监督，不把真人/教师记录插入 on-policy PPO。
优先评估实际检索阶分布、取得核心时间、奖励后能否上场、换主修依据和生存轮数。
本轮不添加“每合成一次就奖励”的系数，不以最终金棋数替代上述指标，也不授权长训练。
