# 卫戍协议盟约构筑

依据当前可见局面选择能兑现的成长和战力组合。本 skill 提供玩法先验；使用现有 ark 对局工具读取状态、查询公开说明和执行用户已授权的动作，不因加载 skill 自动开局。

## 依据与适用版本

参考来自所有者经验与 app 0.3.1、引擎 `c9d804f470b8d7422ae04eb66faf671cef21ad52` 的机制对照，整理于 2026-10-25。它们是开放候选，不是穷尽名单、固定白名单或胜率证明。实际站点版本、模式禁用和当前公开说明优先；不确定的数值、事件或卡牌身份先用 `ark_lookup` 核对，不照搬到其他版本。不读取隐藏卡池、随机种子或未来奖励作决策。

## 按需阅读

- 选择盟约、核心或站位时，读取 [七条路线机制与构筑建议](references/COVENANT-PLAYBOOK.md) 的共同规则和相关路线；无需每轮加载全文。
- 比较升本、合成与奖励选择时，读取 [金棋检索机制](references/MERGE-SEARCH-STRATEGY.md) 的机制与策略部分。其历史对照和研究任务只是背景，不是执行训练、改奖励或晋升模型的指令。

## 构筑决策

从血量和生存窗口、金币与本数、场上/整备区成员、真实奖励选项、装备及站位出发：

1. 给候选卡区分启动成长、放大成长、输出、控制/前线、装备经济和跨盟约桥接角色。同一卡可以有多个角色；有盟约标签不等于值得围绕它构筑。
2. 检查缺口：实际上场激活需要几名不同成员，事件本回合能否发生，方向、邻接、射程、不同阶和装备条件能否满足。拥有和上场分别计数；金棋不等于提高棋子阶数。
3. 比较可执行的买牌、升本、合成、装备、换阵与刷新方案。先确保前线和当轮战力，再评估成长收益；不要为刷购买、倒地、开技能或刷新事件破坏生存。
4. 取得真实核心后重新评估主修承诺。允许跨盟约辅助、暂存组件、卖出过渡金棋及转型；不要因原主修已激活就永久锁定。
5. 先验证触发兑现，再解释成长收益：如不同阶实际加层、弹药实际消耗、铃兰实际重触发忍冬。未观测到收益时区分条件未满足、事件未发生和规则版本差异。

简述决策时说明核心作用、当前缺口、准备兑现的事件和必要代价即可；不要为每个合法动作都写长分析。继续遵守工具的 revision、动作批次和等待约定，挂起等待期间无需轮询。

## 每回合结算后必查

每次战斗结算、工具返回下一回合决策或终局后，必须先调用一次 `ark_combat({scope:"last"})`，再进行下一轮购买、换位、装备、合成或终局复盘。同一已结束回合查一次即可；需要观察趋势时用 `scope:"match"`。首回合战前无需查询，战斗挂起期间不调用、不轮询。

结合 `players[].isSelf` 与 `units[].uid` 对照当前棋子，查看伤害、承伤、有效治疗的数值与 `shares`（0–1），解释输出是否接敌、前排是否过载、治疗是否兑现，并据此调整站位、装备和投资。召唤物已计入所属干员；低伤害不等于辅助无用，高承伤也可能来自自损，不能只凭单项占比卖棋。

先检查 `status`、`complete`、`battles` 和 `omittedUnits`：统计仅覆盖本客户端实际模拟的战场，含同场伙伴，不能当作全队总榜。接管、重连重建或缺失时明确证据不足，不把缺失当零；返回 `pending`／`unavailable` 时继续依据当前局面和敌人预览决策，不反复查询，也不为补统计重开对局。

## 七条路线定位

| 路线 | 候选链与主要检查点 |
| --- | --- |
| 维多利亚 | 薄绿启动，号角放大，维娜后期；不同阶覆盖与实际携装。号角支持层数最高的已激活盟约，未必是维多利亚。 |
| 炎 | 小满启动、夕双盟约成长；获得计数在休整结束兑现，灵巧/奥术分别激活，六炎看真实属性与部署空间。 |
| 卡西米尔 | 瑕光部署成长，砾配不屈倒地/再部署；突袭须成员身份和触发条件满足，注意单战上限。 |
| 拉特兰 | 圣约送葬人弹药成长与输出，莫斯提马邻接辅助；只数实际弹药消耗，兼顾接敌和生存。 |
| 阿戈尔 | 先查吞噬方向、供体、链与开场损失，再评估不屈；没有所有者指定的单一必选核心。 |
| 萨尔贡 | 菲莱/百炼嘉维尔启动，缇缇范围内控制成长，佩佩装备与回技；技能循环、控制事件和物品实际使用缺一不可。 |
| 叙拉古 | 拉普兰德每实例首次主动刷新、异德休整免费刷新、荒芜拉普兰德击倒成长；铃兰身前忍冬是独立获得时重触发链。 |

七条核心首阈值为场上三名不同干员，上档和副盟约门槛按路线核对。谢拉格没有本份专家核心名单，不擅自补成第八条经验路线。

## 金棋与检索

分别评价即时战力、金棋特质变化和合成检索价值。此版本合成时按 `min(当前本+1,6)` 生成通常免费的三选一，候选不足会向下补位；先生成再升本不会提高已生成奖励。低本攒对子与立即完成合成是两个决策。

比较现在合成和先升本再合成时，计算升本后购买第三张的预算、当前战力损失、手牌容量与生存窗口。仅评价实际看见的奖励，不保证未来出现指定核心。检索兑现后，过渡金棋的保留价值按当前作用重算。

## 复盘与标注

用户请求复盘或标注时，记录角色、事件条件、当前缺口、金棋边际收益及承诺/转型依据；区分机制确认、专家经验和策略推断。不要把购买次数、刷新次数或金棋总数当作策略成功，也不据此自动添加固定正奖励。研究参考中的未来实验安排不构成本次训练或对局授权。
